Aviso de privacidad

Versión del 27 de agosto de 2026. Este aviso se aplica a consultas y servicios coordinados directamente con Scriptorium.

En breve

La web no tiene cuentas, analítica ni una base de datos de formularios. El formulario prepara un mensaje en tu propio dispositivo.

No envíes archivos sensibles antes de acordar un canal y un alcance.

1. Responsable

El responsable es Josue Puglla, titular de Scriptorium Language Studio, Ecuador. Contacto para privacidad: josuepug@gmail.com y WhatsApp +593 98 741 1592.

La dirección contractual y la identificación tributaria aplicable constarán en la propuesta, contrato o comprobante emitido cuando corresponda.

2. Datos y origen

Scriptorium puede recibir nombre, datos de contacto, tipo de servicio, idiomas, extensión, fecha, descripción del proyecto y los documentos que el cliente decida compartir. Los datos llegan directamente del interesado por correo, WhatsApp o Fiverr.

3. Finalidades y base

Los datos se usan para responder consultas, evaluar viabilidad, preparar cotizaciones, ejecutar el servicio, entregar archivos, facturar cuando corresponda y atender revisiones o reclamos. El tratamiento se apoya en la solicitud de medidas precontractuales, la ejecución del contrato, obligaciones legales y, cuando sea necesario, consentimiento informado.

4. Plataformas y destinatarios

Según el canal elegido, la información puede ser procesada por Google/Gmail, Meta/WhatsApp o Fiverr bajo sus propias condiciones y ubicaciones de tratamiento. No se vende información personal ni se usa para publicidad de terceros.

5. Conservación

Las consultas que no se conviertan en servicio se conservarán por un máximo de 12 meses, salvo solicitud de eliminación o necesidad legítima de conservar evidencia. Los datos contractuales, de pago y facturación se conservarán durante el periodo exigido por la normativa aplicable. Los archivos de trabajo deben eliminarse o devolverse conforme al acuerdo de cada proyecto.

6. Datos sensibles y menores

No envíes historias clínicas, identificaciones, expedientes legales, datos de investigación identificables ni información de terceros mediante el formulario inicial. El servicio no está dirigido a menores sin intervención de su representante legal.

7. Derechos

Puedes solicitar acceso, rectificación, actualización, eliminación, oposición, limitación o portabilidad, y revocar el consentimiento cuando corresponda. Escribe a josuepug@gmail.com con el asunto “Privacidad”. También puedes acudir a la autoridad ecuatoriana de protección de datos.

8. Cookies y medición

Actualmente el sitio no instala analítica publicitaria ni cookies de seguimiento. GitHub Pages puede procesar datos técnicos necesarios para servir la página conforme a sus propias políticas.

9. Cambios

Este aviso se actualizará cuando se incorpore dominio propio, pagos, analítica, almacenamiento de formularios o nuevos proveedores. La fecha de versión permite identificar el texto vigente.
